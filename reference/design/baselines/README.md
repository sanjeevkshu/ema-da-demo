# Approved Figma baselines

PNG exports of Figma frames, approved for the `visual-figma` layer of the
design gate. Name them `<page>-<width>.png` (`contact-1440.png`), with the
page slug as in `.github/page-types.json` (`index` for the home page).

Get them from Actions → "Design drift" → Run with "export frames", review each
against the build, then commit the ones you approve. See
`.claude/skills/design-compliance/SKILL.md`.
